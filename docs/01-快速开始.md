# ifmap 快速开始

> 适用版本：`0.1.0-SNAPSHOT`　作者：caijun

---

## 1. 环境要求

| 项 | 要求 |
| --- | --- |
| JDK | **8 及以上**（`ifmap-core` 字节码目标为 Java 8；已在 JDK 8 / JDK 17 下实测构建通过） |
| 构建 | Maven 3.6+ |
| 运行期依赖 | `slf4j-api`（日志门面，由宿主提供实现） |
| Spring | **不需要**（纯 Java 可用）；Spring Boot 3 场景见 §6 |

## 2. 引入依赖

```xml
<dependency>
  <groupId>cn.cj</groupId>
  <artifactId>ifmap-json-jackson</artifactId>
  <version>0.1.0-SNAPSHOT</version>
</dependency>
```

依赖传递关系：

```
ifmap-json-jackson ──► ifmap-core ──► slf4j-api
        │
        └─► jackson-databind / json-path（默认 JSON 实现）
```

想换 JSON 库：只依赖 `ifmap-core`，自己实现 `JsonOps` 接口（见 §5.2）。

## 3. 最小可运行示例

```java
import cn.cj.ifmap.core.IfmapEngine;

public class Demo {
    public static void main(String[] args) {
        // 1. 引擎：自动发现 JsonOps 实现 + 注册 18 个内置规则
        IfmapEngine engine = IfmapEngine.createDefault();

        String templateJson = "{"
                + "\"orderNo\": \"$.orderNo\","
                + "\"dueDate\": \"@FUN(dateFormat,$.dueDate,yyyyMMdd)\","
                + "\"total\": \"@FUN(numSum,$.amounts,2,HALF_UP)\""
                + "}";

        String sourceJson = "{"
                + "\"orderNo\": \"PO001\","
                + "\"dueDate\": \"2026/03/31\","
                + "\"amounts\": [100.5, 300.24]"
                + "}";

        // 2. 启动期校验（强烈建议做，见 §4）
        engine.validateTemplate("demo-01", templateJson);

        // 3. 渲染
        System.out.println(engine.render(templateJson, sourceJson));
        // {"orderNo":"PO001","dueDate":"20260331","total":"400.74"}
    }
}
```

可运行示例工程：`ifmap-demo-pure-java`（含 5 段演示：构建引擎、启动期校验、渲染、
规则名拼错被拦下、规则清单）：

```bash
mvn -q -pl ifmap-demo-pure-java exec:java
# 或
java -cp ifmap-demo-pure-java/target/classes:... cn.cj.ifmap.demo.IfmapQuickStart
```

## 4. 启动期模板校验（最重要的一条实践）

**问题**：模板里规则名拼错（例如把 `formatDate` 写成 `farmatDate`）时，引擎在**运行期**才去反射调用，
调用不到就返回 null；存量引擎甚至会把 `@FUN(farmatDate,...)` 原文写进报文，形成脏数据，且**永远不会报错**。

**做法**：应用启动时把全部模板扫一遍做校验，把问题提前到启动阶段。

```java
@Component
public class IfmapTemplateValidator implements ApplicationRunner {

    private final IfmapEngine engine;
    private final TemplateConfigRepository repository;   // 你的模板存储（DB / 配置中心 / classpath）

    @Override
    public void run(ApplicationArguments args) {
        Map<String, String> templates = repository.loadAll();   // templateId -> templateJson
        try {
            engine.validateTemplates(templates);
        } catch (StartupValidationException e) {
            // 日志里会有：模板中存在未注册的规则...  - czb-apply-01 -> [farmatDate]
            throw new IllegalStateException("接口映射模板校验失败：" + e.getMissingRules(), e);
        }
    }
}
```

校验失败示例输出：

```
模板中存在未注册的规则，已阻断启动：
  - czb-apply-01 -> [farmatDate]
已注册规则：[concat, dateAdd, dateConvert, ...]
```

## 5. 常用配置

### 5.1 构建引擎

```java
IfmapEngine engine = IfmapEngine.builder()
        .nullPolicy(NullPolicy.SKIP_FIELD)   // 默认值；见 §5.3
        .register(new MyBankRules())         // 追加自定义规则
        .build();
```

### 5.2 替换 JSON 实现

```java
IfmapEngine engine = IfmapEngine.builder()
        .jsonOps(new FastjsonJsonOps())      // 实现 cn.cj.ifmap.core.json.JsonOps
        .build();
```

`JsonOps` 契约（**只用 JDK 类型**，公开 API 不出现任何 JSON 库类型）：

```java
Object parse(String json);                       // -> Map / List / String / Number / Boolean / null
String toJson(Object value);
JsonReadContext readContext(String json);        // 解析一次、多次取值
boolean isJson(String text);
```

也可在 `META-INF/services/cn.cj.ifmap.core.json.JsonOps` 里声明实现，SPI 自动发现。

### 5.3 空值策略

| 值 | 行为 |
| --- | --- |
| `SKIP_FIELD`（默认） | 字段不出现 |
| `EMPTY_STRING` | 输出 `""` |
| `FAIL` | 抛 `IfmapConfigException`（消息含模板字段路径），适合对报文完整性要求高的接口 |

### 5.4 上下文与工作日历

```java
RuleContext ctx = RuleContext.builder()
        .tenantId("T001")
        .interfaceNo("IF_CZB_0001")
        .attribute(RuleContext.ATTR_HOLIDAY_CALENDAR, holidayCalendar)
        .build();

Map<String, Object> target = engine.renderToMap(templateJson, sourceJson, ctx);
```

`HolidayCalendar` 是函数式接口，宿主用一张节假日表实现它即可：

```java
HolidayCalendar calendar = date -> !holidaySet.contains(date);
```

不提供时按「周一~周五工作日」的简化口径计算。

## 6. Spring Boot 3 接入（规划中）

W1 骨架**尚未**提供 starter；规划中的用法（W3 里程碑交付）：

```yaml
ifmap:
  table-prefix: ifmap_
  null-policy: SKIP_FIELD
  validate-on-startup: true
```

```java
@Autowired
private IfmapEngine ifmapEngine;             // starter 自动装配
```

在没有 starter 之前，用 `@Configuration` 手工装配即可：

```java
@Configuration
public class IfmapConfig {

    @Bean
    public IfmapEngine ifmapEngine(List<IfmapRule> ruleBeans) {
        IfmapEngine.Builder builder = IfmapEngine.builder();
        for (Object rule : ruleBeans) {
            builder.register(rule);
        }
        return builder.build();
    }
}
```

## 7. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 运行时打印 `No SLF4J providers were found` | 宿主没引日志实现，属正常提示；引入 `slf4j-simple`/`logback`/`log4j2` 任意一个即可 |
| 数字变成了字符串（`100` → `"100"`） | **有意行为**：银行报文里的金额/数量就是字符串，见 `docs/02-模板DSL语法.md` §2.1 |
| 通配路径取出来的数组长度不一致 | 路径里带 `*` 会自动补 null 对齐；不带 `*` 时 JsonPath 会丢掉取不到的叶子 |
| `RuleNotFoundException` | 规则名拼错或自定义规则没注册；用 `engine.validateTemplate` 提前发现 |
| `RuleArgumentException` | 规则入参非法（如 `numFormat` 的 style 写错），消息里会列出可用取值 |
| `@FUN` 参数里想写逗号 | 不支持（参数按逗号切分）；码值表达式用 `;` 分隔映射对 |
| `@array@` 输出的 key 变成了空字符串 | key 必须是 `字段名@array@$.path`，**字段名不能省** |
| 字段整个消失了 | 取值为 null 且策略是 `SKIP_FIELD`；想保留空串用 `NullPolicy.EMPTY_STRING` |
